# Курсовой проект: Анализ транзакций

## 📋 Описание проекта

Проект реализует веб-сервис для анализа и обработки пользовательских транзакций. Основной функционал включает отображение главной страницы, простой поиск по транзакциям и формирование отчетов о тратах по категориям.

---

## 🚀 Функциональность

### 🔹 Главная страница (`views.py`)
- Реализована функция для формирования главной страницы.
- Принимает строку с датой и временем в формате `YYYY-MM-DD HH:MM:SS`.
- Возвращает корректный JSON-ответ согласно ТЗ.
- Используются вспомогательные функции из `utils.py`.

#### Используемые библиотеки:
- `json` — сериализация данных
- `datetime` — работа с датой и временем
- `logging` — ведение логов
- `pandas` — обработка табличных данных
- Внешние API — получение курсов валют, цен акций и пр.

---

### 🔹 Сервисы (`services.py`)
#### Простой поиск
- Реализован функционал «Простой поиск» по транзакциям.
- Принимает строку-запрос и DataFrame транзакций.
- Возвращает корректный JSON-ответ.
- Использует библиотеки:
  - `json`
  - `logging`

---

### 🔹 Отчеты (`reports.py`)
#### Траты по категории
- Реализован отчет по тратам за последние 3 месяца.
- Принимает:
  - `DataFrame` транзакций
  - название категории
  - дату отсчета
- Возвращает корректный JSON-ответ.
- Использует библиотеки:
  - `json`
  - `datetime`
  - `logging`
  - `pandas`

---

## ✅ Тестирование

- Покрытие тестами: **80%**
- Все тесты успешно проходят при запуске `pytest`
- Используются:
  - `Mock` и `patch` для изоляции внешних зависимостей
  - `pytest.fixture` — фикстуры для генерации тестовых данных
  - `pytest.mark.parametrize` — параметризация тестов

## 📦 Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Babka_Shura/kursovaja_proj1.git
   cd your-repo
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запуск тестов:
   ```bash

   ```
